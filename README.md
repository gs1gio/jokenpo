App Jokenpo
---

Aplicativo mobile desenvolvido no Android Studio utilizando Java e XML, baseado no clássico jogo Pedra, Papel e Tesoura.

Objetivo da Atividade
---
Criar um aplicativo interativo onde o usuário escolhe entre:

Pedra

Papel

Tesoura

O aplicativo gera uma escolha aleatória e exibe:
---

A jogada do app;

O resultado da partida;

O placar atualizado.

Funcionalidades Implementadas
---
Escolha de jogadas através de imagens clicáveis;

Geração aleatória da jogada do aplicativo;

Exibição do resultado:
---
Vitória

Derrota

Empate

Sistema de placar:
---
Pontos do jogador

Pontos do aplicativo

Botão para reiniciar o jogo e zerar o placar.

Componentes Utilizados
---
TextView

ImageView

Button

ConstraintLayout

Responsável pela lógica do jogo:
---

Captura da escolha do jogador;

Sorteio da escolha do aplicativo;

Comparação das jogadas;

Atualização do resultado e do placar;

Reinicialização da partida.

Tecnologias Utilizadas
---
Java
XML
Android Studio
ConstraintLayout
Autor

Projeto desenvolvido para prática de desenvolvimento Android, manipulação de eventos e lógica de programação mobile.
